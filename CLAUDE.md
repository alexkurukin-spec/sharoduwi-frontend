# CLAUDE.md — Sharoduwi Frontend

Конституция проекта. Правила здесь имеют приоритет над разовыми промптами. При конфликте — побеждает этот файл.

**Полная спека:** @docs/PROMPT.md — перечитывай раздел соответствующей фазы перед началом работы над ней.

**Аддон дизайна:** @docs/PROMPT-addon.md — фронтенд-концепция Awwwards-уровня (визуальный язык, анимации, wow-фичи). **Решение владельца:** реализуем визуальный язык аддона — Full Palette (яркие акценты, цветные секции, категорийные цвета), шрифты Unbounded + Manrope. Это переопределяет прежнее правило «сдержанной палитры». Архитектура (RSC, nuqs-фильтры, серверная пагинация, корзина на Zustand, зональная логика) остаётся по базовой спеке, если явно не сказано иное.

---

## Проект

Фронтенд интернет-магазина гелиевых шаров и праздничного декора (Sharoduwi). Только фронтенд; бэкенд — AdvantShop через REST на сабдомене. На старте — моки, переход на REST не должен трогать компоненты.

**Бизнес-цель:** №1 по выручке в Московской агломерации. Плацдарм — юго-восток МО (Жуковский, Раменское, Люберцы, Малаховка), радиус расширяется к Москве зона за зоной. **Зона доставки — первичный параметр опыта.**

Две аудитории: мамы/семьи (просмотр, сборка композиций) и мужчины (быстрый путь к готовому набору на выписку/рождение). UI обслуживает оба.

## Стек (зафиксировано, альтернатив не предлагать)

Next.js 15 App Router + RSC · TypeScript strict (+ `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`) · Tailwind v4 + shadcn/ui · Zustand (только корзина) · nuqs v2 (фильтры в URL) · Framer Motion + чистый CSS · React Three Fiber (только hero) · `@tanstack/react-virtual` · `embla-carousel-react` · `react-hook-form` + `zod` · `lenis` · pnpm.

**Не ставить:** Jotai, Redux, Swiper, react-window, react-virtualized, styled-components.

---

## Правила (не нарушать)

1. **RSC по умолчанию.** `"use client"` только на листьях-островах. Никогда на `layout.tsx` / `page.tsx`.
2. **UI не знает про AdvantShop.** Данные — только через `lib/shop/api.ts` и доменные типы. Поля AdvantShop живут только в `mappers.ts`.
3. **Зона доставки — первичный параметр.** Доступность товара, способ получения, слот и цена выводятся из зоны пользователя, не хардкодятся. Зональная логика — только в `lib/shop/zones.ts`.
4. **Анимационный бюджет.** Hover и массовое — CSS; Framer Motion — только острова; R3F — только hero; layout-анимации в гриде запрещены.
5. **Фильтры — в URL через nuqs.** Отдельного стора фильтров нет.
6. **Корзина — Zustand + persist + `skipHydration`.** Бейдж рендерить только после регидрации. Дедуп по `key`.
7. **TS строгий.** Ноль `any`. Ответы внешних API валидировать zod на границе.
8. **Не переусложнять.** Не добавлять абстракции, библиотеки и фичи вне спеки без явного запроса. Реализовывать минимально достаточное под текущую фазу.

## Как работать

- Идти строго по фазам 0 → 7 из @docs/PROMPT.md. Каждую фазу довести до её критерия «принято» прежде чем начинать следующую.
- **Коммит после каждого «принято».** Задачи держать в рамках одной фазы — так сорвавшаяся сессия не откатывает прогресс.
- Команды: `pnpm dev`, `pnpm typecheck`, `pnpm build`. После каждой фазы `pnpm typecheck` должен быть зелёным.
- Не начинать новую фазу, пока предыдущая не закоммичена и не проходит typecheck.
