## ФРОНТЕНД-КОНЦЕПЦИЯ

### Визуальный язык и эмоция

Сайт — это праздник с первого пикселя на светлом, воздушном фоне.
Яркость достигается не тёмным фоном, а насыщенными цветами секций,
крупной типографикой и живыми фотографиями продуктов.

**Цветовая стратегия: Full Palette (праздничная, светлая)**

```
Фон страницы:   #FFFFFF  (чистый белый — максимальный контраст для фото шаров)
Фон секций:     чередуются — белый / #FFF5FB (нежный розовый) / #F0F9FF (нежный голубой)
                Это создаёт ритм и визуальное дыхание без серости.

Акцент 1:       #FF2D87  (hot pink — главный, кнопки CTA, теги)
Акцент 2:       #FFB800  (солнечный жёлтый — цена, badges, выделения)
Акцент 3:       #00C2FF  (sky blue — ссылки, иконки)
Акцент 4:       #A855F7  (фиолетовый — категория «свадьба», «выпускной»)
Акцент 5:       #22C55E  (зелёный — «в наличии», скидки)

Текст primary:  #1A1A2E  (почти чёрный с лёгким синим оттенком, не #000)
Текст secondary:#6B7280
Карточки:       #FFFFFF с border 1px solid #F0F0F0
```

Визуальная аналогия: витрина магазина подарков в солнечный день —
всё яркое, чистое, хочется зайти и потрогать.

**Типографика:**
- Заголовки h1–h2: Unbounded (кириллица, geometric rounded, сверхжирный 800–900).
  Размер: ≥ 56px десктоп, ≥ 36px мобайл. Цвет: #1A1A2E или акцент.
- Отдельные слова в h1 выделяются акцентным цветом (#FF2D87) — не весь заголовок.
- Body / UI: Manrope 400/500, line-height 1.6.
- Цены: Unbounded 700, акцент 2 (#FFB800).

**Секции с цветным фоном (Full Palette в действии):**
Некоторые секции — не белые, а залиты насыщенным акцентом:

```css
/* Hero или промо-блок «Хиты» */
background: linear-gradient(135deg, #FF2D87 0%, #A855F7 100%);
color: #fff;

/* Секция «Как заказать» */
background: #FFF5FB;

/* Секция «Категории» — чередование карточек */
/* каждая карточка категории — свой цвет фона из палитры */
```

**Категорийные цвета (--category-accent на layout):**
```
День рождения:  #FF6B6B  (coral)
Свадьба:        #F472B6  (pink)
Новый год:      #22C55E  (зелёный)
Выпускной:      #FFB800  (золото)
23 февраля:     #3B82F6  (синий)
8 марта:        #FF2D87  (hot pink)
Детский:        #A855F7  (фиолетовый)
Корпоратив:     #06B6D4  (cyan)
```

Карточки категорий: фото на весь блок + цветная подложка под названием
в цвете своей категории. При hover — карточка чуть приподнимается
(translateY -6px) и тень усиливается.

### Стек анимаций (конкретный)

```
Scroll-based:   Framer Motion (useScroll + useTransform) — параллакс hero,
                reveal карточек, sticky-секции каталога.
                НЕ GSAP ScrollTrigger — лишняя зависимость без выигрыша.

Page transitions: Framer Motion AnimatePresence — мягкий fade+slide между
                  страницами через layout.tsx.

Micro-interactions: CSS transitions (transform + opacity) — hover карточек,
                    кнопки, теги фильтров. Framer Motion здесь избыточен.

Сложные эффекты (только hero и 2–3 wow-секции):
                react-spring для физичного bounce эффекта шаров.
                Lottie (через @lottiefiles/react-lottie-player) для анимации
                иконок (сердечко, звёздочка, корзина) — SVG, не видео.

Плавный скролл: Lenis (последняя версия) — подключается глобально в layout.tsx.
                Обязательно: reducedMotion check через prefers-reduced-motion.

3D / WebGL:     НЕ использовать на каталоге и карточках — просаживает mobile.
                Допускается один R3F-эффект на главной hero (плавающие шары
                как particle-система) при условии lazy load + Suspense + fallback.
```

**Правило производительности:** анимация = только transform и opacity.
Никакого layout thrashing (top/left/width/height в keyframes).

### Главная страница

**Hero-блок:**
- Полноэкранный (100dvh). Крупный h1: «Шары для вашего праздника».
- Справа или по центру — фото/видео флагманской композиции, обрезанное
  органической формой (clip-path: ellipse или SVG mask).
- Floating-шары как декор: 4–6 PNG-шаров с разной скоростью параллакса
  (Framer Motion useScroll + translateY). Лёгкий, не перегруженный.
- Поверх: строка быстрого поиска с подсказками (по случаю: «день рождения»,
  «свадьба», «выпускной»).

**Секция категорий под hero:**
- Горизонтальный скролл (overscroll-x) на мобайле, 4-колоночная сетка на десктопе.
- Карточка категории: квадрат 1:1, фото на весь блок, название внизу на тёмном
  оверлее. Hover: scale(1.03) + brighten фото. Framer Motion whileHover.

**Хиты продаж / «Выбор мам»:**
- Горизонтальный carousel (Embla Carousel — самый лёгкий, без jQuery).
  Без авто-прокрутки — она раздражает.
- Каждая карточка: фото, название, цена, кнопка «В корзину» — без лишнего.

**Как заказать (3 шага):**
- Три иконки (Lottie) + краткий текст. Одна строка на десктопе.

### Каталог и фильтры

**Структура URL:**
```
/catalog                    — все товары
/catalog/[category]         — категория (ISR, revalidate 600)
/catalog/[category]/[slug]  — карточка товара
```

**Фильтры — реализация:**
- Фильтры передаются через URL search params (?event=birthday&color=red&price_max=2000).
  Это критично для SEO и для работы кнопки «назад».
- Компонент фильтров — клиентский (`"use client"`), остальное — Server Component.
- useSearchParams + useRouter.replace (не push, чтобы не засорять историю).
- Zustand НЕ нужен для фильтров — URL — это стейт.

**Категории фильтров:**
```
По случаю:   день рождения, свадьба, выпускной, новый год, 23 февраля, 8 марта,
             юбилей, детский праздник, корпоратив
По типу:     одиночный шар, букет, арка, колонна, фигура, набор
По цвету:    цветовые чипы (не текст) — palette picker с мультиселектом
По цене:     range slider (кастомный, без библиотеки — 40 строк CSS+JS)
По размеру:  только для одиночных шаров
```

**Визуал фильтров:**
- На десктопе: sidebar слева 240px, sticky position.
- На мобайле: drawer снизу (Radix UI Dialog, aria-ready), открывается кнопкой
  «Фильтры (N)» где N — количество активных. Нет popup модалок.
- Активные фильтры: chips-строка над сеткой товаров с крестиком на каждом.

**Сетка товаров:**
- Masonry-like: CSS grid с auto-rows, изображения разной высоты создают
  живой ритм (НЕ Pinterest-masonry на JS — слишком тяжёлый).
  Карточки 2 колонки мобайл / 3 планшет / 4 десктоп.
- Infinite scroll через IntersectionObserver + React Query (prefetch следующей
  страницы при 80% скролла). НЕ кнопка «Загрузить ещё» — хуже конверсия.
- Skeleton-лоадеры: CSS animated gradient (не спиннер).

### Карточка товара (в сетке)

```
┌─────────────────┐
│                 │  ← фото 3:4, object-fit cover
│   [фото]        │  ← lazy load, next/image, sizes="(max-width:640px) 50vw, 25vw"
│                 │
│  ♡  (избранное) │  ← абсолютно позиционированный, 36×36px tap target
├─────────────────┤
│ Название        │  ← 2 строки max, text-overflow: ellipsis
│ от 1 200 ₽      │  ← «от» если есть варианты
│ [В корзину]     │  ← полная ширина, primary button
└─────────────────┘
```

Hover-состояние (десктоп только, через @media hover:hover):
- фото: scale(1.04), transition 300ms ease-out
- появляется второй снимок (если есть) через opacity 0→1
- кнопка поднимается translateY(-4px)

Карточка — это `<article>` с `<a>` на всю площадь + отдельные интерактивные
элементы (корзина, избранное) с pointer-events: auto поверх.

### Страница товара

**Структура (mobile-first):**
```
1. Галерея (top):
   - Главное фото 1:1 или 4:3
   - Мини-превью строкой (tap → меняет главное)
   - Pinch-to-zoom через touch events (нативный, без библиотеки)
   - На десктопе: hover-zoom (CSS transform + overflow hidden)

2. Блок заказа (под галереей или sticky sidebar на десктопе):
   - Название h1
   - Цена (крупно)
   - Выбор варианта (если есть): цвет, размер — pill-кнопки
   - Кнопка «В корзину» + «Купить сейчас»
   - Доставка: иконка + текст одной строкой

3. Описание (аккордеон):
   - Состав, что входит
   - Размеры и характеристики
   - Как хранить / сколько летит

4. Похожие товары: горизонтальный carousel (те же карточки)
```

### Корзина и чекаут

**Корзина:**
- Drawer справа (Radix UI Sheet) — НЕ отдельная страница.
- Открывается по клику «В корзину» — товар добавляется с анимацией
  (mini fly-to-cart через Framer Motion layoutId).
- Zustand store (`useCartStore`) + persist в localStorage.
- При открытии drawer: список товаров, итог, кнопка «Оформить заказ».

**Стейт корзины (Zustand):**
```ts
interface CartStore {
  items: CartItem[]           // { id, name, price, qty, image, variantId }
  addItem: (item) => void
  removeItem: (id, variantId) => void
  updateQty: (id, variantId, qty) => void
  clear: () => void
  total: () => number         // computed via get()
}
```

**Чекаут — одна страница `/checkout`:**
```
Шаг 1 (всегда виден): Контакты (имя, телефон, email)
Шаг 2: Доставка или самовывоз
Шаг 3: Дата/время (calendar picker — react-day-picker)
Шаг 4: Комментарий (textarea)
Итог: сводка заказа (sticky на десктопе)
Кнопка: «Оформить и оплатить» → POST на AdvantShop API
```

Валидация: react-hook-form + zod. Ошибки — inline, под полем, не тост.
После успешного заказа: `/order/success?id=XXX` — статическая страница с
благодарностью и кнопкой «Поделиться» (Web Share API).

### Wow-фичи (4 штуки, реалистичные)

**1. Категорийный акцент-цвет**
Каждая категория задаёт CSS-переменную `--accent` через `data-category` на `<html>`.
Хлебные крошки, активные фильтры, кнопки — всё подхватывает цвет категории.
«Свадьба» — нежный розовый, «Новый год» — красный, «День рождения» — яркий coral.
Реализация: 20 строк CSS + generateStaticParams в layout.

**2. Fly-to-cart анимация**
При нажатии «В корзину» миниатюра товара «летит» в иконку корзины в навбаре.
Framer Motion layoutId + shared layout animation. Нет Canvas, нет клонирования DOM.
Время реализации: 2–3 часа. Эффект: запоминается навсегда.

**3. Живой поиск с превью**
Поисковая строка в header: при вводе открывается dropdown с превью товаров
(фото + цена + ссылка) прямо в оверлее. Debounce 300ms → GET /api/search.
Реализация: Radix Popover + React Query + AdvantShop search API.
Без библиотеки автокомплита — только нативный.

**4. Умный фильтр «По случаю» на главной**
Вместо breadcrumbs — блок «Что празднуем?» с 8 кнопками-эмоджи+текст.
Клик → переход на `/catalog?event=birthday` с уже применённым фильтром.
SEO: каждый event = отдельная статическая страница с уникальным текстом.
Это самый конверсионный элемент — пользователь выбирает не «Шары» а «Праздник».

## ЧТО НЕ ДЕЛАТЬ (антипаттерны для этой ниши)

- Не ставить hero-slider с авто-прокруткой — конверсия ниже, CLS выше.
- Не использовать popup с акцией при входе — ЦА (мамы) закрывают и уходят.
- Не делать «Зарегистрируйтесь для покупки» — только guest checkout.
- Не показывать остаток «осталось 2 шт» если товар производится под заказ.
- Не использовать дешёвые stock-фото шаров — только реальные фото своих работ.
- Не ставить видео-фон в hero без fallback для медленного интернета.
- Не делать мобильный hamburger с 3-уровневым меню — max 2 уровня.
